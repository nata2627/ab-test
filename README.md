# A/B-эксперимент на Criteo Uplift

Разбор рандомизированного эксперимента с рекламой на открытом наборе Criteo Uplift v2.1: мощность до анализа, проверка рандомизации, основной тест, бутстреп, CUPED, подглядывание и последовательный тест. Работа идет, результатов пока нет.

Данные: Criteo Uplift v2.1, лицензия CC BY-NC-SA 4.0. Diemert E., Betlei A., Renaudin C., Amini M.-R. A Large Scale Benchmark for Uplift Modeling. AdKDD 2018. Данные в репозиторий не кладутся, их скачивает `scripts/download_data.sh`.
